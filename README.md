# RIM Productions site
1. Supabase: SQL Editor, run supabase.sql. Then Project Settings > API: copy Project URL and anon key into config.js.
2. Edit config.js (WhatsApp, email), services.js (prices), add MP3 previews to assets/.
3. GitHub: upload all files to a repo, Settings > Pages > Deploy from branch > main > /(root).
View orders: Supabase > Table Editor > orders.# creatives
